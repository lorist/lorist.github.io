01
Call Initiated
A Pexip client dials in. Infinity needs to make a policy decision before admitting the participant.
02
Request → Proxy
Infinity sends an HTTP GET to the proxy with all call parameters. The proxy verifies Basic Auth credentials and optionally checks the source IP.
3a
→ ABAC
If service_tag matches ^\[SEC=…CAVEAT=RI:…\]$, forwarded to the ABAC server for clearance-based decisions.
3av
→ ABAC Avatar
Infinity calls /policy/v1/participant/
avatar/{alias} to fetch participant images. A catch-all avatar rule forwards all requests to ABAC, which returns a binary JPEG/PNG streamed back unchanged.
3b
→ Web Scheduler
If local_alias matches ^(sip:)?99\d{9}…$ — an ANZSEC 11-digit VMR — routes to the Pexip Web Scheduler.
3c
→ Mattermost
If local_alias matches ^[a-z0-9]{26}$ — a Mattermost channel ID — the service_configuration request routes to Mattermost.
04
Response → Infinity
The upstream response is passed back to Infinity unchanged — JSON policy decisions or binary avatar images. Every request is logged with matched rule, upstream, identity, and response time.
